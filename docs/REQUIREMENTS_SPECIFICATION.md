# 요구사항 정의서 (Requirements Specification)

**프로젝트명**: Pack to Go (여행 협업 및 일정·예산·갤러리 관리 서비스)  
**작성일**: 2026-08-21  
**문서 버전**: v1.0.0  
**상태**: 기준 소스 코드 기반 최신화 완료  

---

## 1. 프로젝트 개요

### 1.1 배경 및 목적
- **Pack to Go**는 여행을 계획하고 진행하는 사용자들이 여행 정보, 일정, 예산, 멤버, 사진 기록을 실시간으로 공유하고 협업할 수 있도록 돕는 웹 기반 여행 통합 관리 플랫폼입니다.
- 구글 계정 기반의 간편한 로그인과 이메일 화이트리스트 접근 제어를 통해 비공개 여행 그룹의 보안성을 확보합니다.
- Gemini 2.5 Flash 기반의 AI 여행 비서를 통합하여 여행지에 특화된 정보 검색 및 실시간 추천을 지원합니다.

### 1.2 시스템 범위
- **사용자 인증 및 권한 관리**: 구글 소셜 로그인, 이메일 화이트리스트 기반 접근 제어, 방장(Owner)/일반 멤버/관리자 권한 분리
- **여행 탐색 및 대시보드**: 참여 중인 여행 목록 조회, D-Day 계산, 참여자 프로필 스택, 기본 정보 카드
- **여행 상세 및 가이드**: 여행지 소개, 날씨 및 추천 복장, Google Maps 지도 임베드 및 외부 연동, 명소 이미지 캐러셀
- **일정 관리 (Itinerary)**: Day별 일정 탭 전환, 시간 순 타임라인 뷰, 활동별 상세 아코디언, 장소 지도 연동
- **예산 및 지출 관리 (Budget)**: 총 예산 대비 지출 분석, 잔여 예산 및 지출률 계산, 카테고리별 차트, 지출 내역 및 결제자 매핑
- **멤버 협업 관리 (Members)**: 방장 전용 이메일 초대, 참여 멤버/초대 대기 멤버 목록 조회, 멤버 내보내기/초대 취소
- **여행 갤러리 (Gallery)**: 사진 5장 제한 업로드(방장 전용), 클라이언트 이미지 압축 및 Firestore 저장, 모달 뷰어, 실시간 댓글
- **AI 여행 비서 (Gemini Chat)**: 여행지 맞춤형 스트리밍 AI 챗봇

## 2. 사용자 역할 및 권한 정의 (User Roles & Permissions)

| 역할 (Role) | 정의 및 권한 범위 | 식별 방식 |
| :--- | :--- | :--- |
| **시스템 관리자 (Admin)** | - 시스템 내 모든 여행 목록 및 상세 정보 열람 가능<br>- 접근 승인 화이트리스트 무조건 통과 | `users.role === 'admin'` 또는 지정된 관리자 이메일 (`inchul17.kim@gmail.com`) |
| **여행 방장 (Trip Owner)** | - 해당 여행의 최고 권한자<br>- 멤버 초대 및 내보내기<br>- 갤러리 사진 업로드(최대 5장) 및 사진 삭제 권한 보유 | `trip.ownerId === user.uid` |
| **참여 멤버 (Collaborator)** | - 초대받아 여행에 참여한 사용자<br>- 여행 개요, 일정표, 예산, 갤러리 조회<br>- 갤러리 사진 댓글 작성<br>- AI 여행 비서 질의응답 | `trip.collaboratorIds`에 UID 포함 또는 `trip.collaboratorEmails`에 이메일 포함 |
| **초대 대기자 (Pending User)** | - 방장이 이메일로 초대한 사용자 (로그인 시 자동으로 승인 및 참여 처리) | `trip.collaboratorEmails` 및 `allowed_emails` 컬렉션에 등록 |
| **미인가 사용자 (Unauthorized)** | - 화이트리스트에 등록되지 않은 구글 계정 사용자<br>- 로그인 시도시 접근 차단 및 자동 로그아웃 | `allowed_emails` 및 참여 여행 미보유 |

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 회원 인증 및 접근 제어 (FR-AUTH)

| 요구사항 ID | 기능명 | 상세 요구사항 명세 | 중요도 |
| :--- | :--- | :--- | :--- |
| **FR-AUTH-01** | 구글 소셜 로그인 | - Firebase Authentication의 `GoogleAuthProvider`를 통한 팝업(`signInWithPopup`) 로그인 지원<br>- 로그인 완료 시 인증 상태 자동 감지 및 인가 검증 프로세스 진입 | 필수 (High) |
| **FR-AUTH-02** | 화이트리스트 인가 검증 | - 로그인 사용자의 이메일이 인가 대상인지 확인:<br>&nbsp;&nbsp;1) 시스템 관리자 이메일 일치 여부<br>&nbsp;&nbsp;2) `allowed_emails` 컬렉션에 등록 여부<br>&nbsp;&nbsp;3) 참여 중인 여행의 `collaboratorEmails` 포함 여부<br>&nbsp;&nbsp;4) 레거시 `collaboratorIds` 포함 여부<br>- 인가된 경우 `users` 컬렉션에 프로필 문서 생성/업데이트 (`status: 'approved'`) | 필수 (High) |
| **FR-AUTH-03** | 비인가 접근 차단 | - 화이트리스트에 없는 사용자는 접근 권한 없음 안내 얼럿 출력 후 강제 로그아웃(`signOut`) 및 `/login`으로 리다이렉션<br>- 로컬 개발 및 프로덕션 전 환경에서 실제 구글 인증 및 화이트리스트 검증 적용 | 필수 (High) |
| **FR-AUTH-04** | 라우트 보호 (AuthGuard) | - `/login` 및 `/api/*` 경로를 제외한 모든 보호 경로에 대해 인증 여부 및 인가 상태 검사<br>- 미인증 상태 시 로그인 페이지로 자동 전환, 로딩 중 스피너 표시 | 필수 (High) |
| **FR-AUTH-05** | 로그아웃 | - 상단 네비게이션 바에서 로그아웃 버튼 클릭 시 세션 종료 및 `/login` 화면으로 이동 | 필수 (High) |

| **FR-TRIP-03** | 여행 상세 진입 | - 여행 카드를 클릭하면 해당 여행의 상세 홈 화면(`/trips/[id]`)으로 네비게이션 이동 | 필수 (High) |

## 4. 비기능 요구사항 (Non-Functional Requirements)

### 4.1 성능 (Performance)
- **NFR-PERF-01 (이미지 최적화)**: 업로드 이미지는 브라우저 캔버스를 통해 800px 이하로 압축 변환 후 저장하여 Firestore 문서당 1MB 용량 제한을 엄격히 준수하고 네트워크 대역폭을 절약합니다.
- **NFR-PERF-02 (렌더링 성능)**: Next.js 16의 Turbopack 빌드 최적화 및 정적 렌더링/동적 라우팅을 적절히 분리하여 초기 로딩 시간을 최소화합니다.

### 4.2 반응형 및 사용성 (Usability & Design)
- **NFR-UX-01 (반응형 지원)**: 모바일(360px~), 태블릿(768px~), 데스크톱(1024px~) 전 해상도에 최적화된 반응형 레이아웃(모바일 상단 탭 스크롤 / 데스크톱 좌측 고정 사이드바)을 제공합니다.
- **NFR-UX-02 (디자인 시스템)**: Tailwind CSS 기반의 모던 글래스모피즘, 정제된 인디고/슬레이트 컬러 팔레트, 상태 패널(`StatePanel`)을 통한 일관된 UI 피드백을 유지합니다.

### 4.3 보안 및 개인정보 (Security)
- **NFR-SEC-01 (API 키 은닉)**: Gemini API Key 및 Firebase Admin 서비스 계정 키는 서버 사이드 환경변수(`.env.local`)에만 보관하며 클라이언트에 노출되지 않습니다.
- **NFR-SEC-02 (접근 통제)**: 클라이언트 사이드 `AuthGuard`와 Firestore 이메일 화이트리스트를 결합하여 비인가 사용자의 데이터 조회를 원천 차단합니다.

### 4.4 신뢰성 및 가용성 (Reliability)
- **NFR-REL-01 (지도 대체 UI)**: 외부 지도 iframe 로드 실패 또는 네트워크 지연 시 6초 타임아웃을 적용하여 외부 Google Maps 링크로 안전하게 대체합니다.
- **NFR-REL-02 (데이터 패치 안정성)**: 데이터 조회 실패 시 에러 상태 화면 및 '다시 시도' 액션을 제공하여 사용자에게 명확한 상태를 안내합니다.
